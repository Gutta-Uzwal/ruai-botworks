# projects

Real client work only. One folder per domain, one folder per client project
inside it:

```text
projects/
  school/
    <client-project-name>/
  restaurant/
    <client-project-name>/
```

A new client project starts as a copy of the matching template under
[`../Templates/<domain>/`](../Templates/), then diverges to the client's
requirements. Its `DESIGN.md` still names the
premium web design standard and the domain brief it was built from — a
client project departs from the template's specifics, not from the standard.

There is no domain here yet with a named client. When the first one lands,
this file's example above becomes real.
