Compliance posture

Obligations attach per project at scoping, from a fixed matrix. Applying every regime to every project is what makes compliance ceremonial; applying none until audit is what makes it fatal.

Attaches by template

  • HIPAA — healthcare
  • PCI-DSS — ecommerce
  • SOC2 — saas-dashboard, crm
PCI DSS — integrate, never implement. Card data does not enter our systems. Hosted fields only, keeping the client in SAQ-A scope. A project that would place a card number in our database is rescoped or declined, and security-engineer holds that line as a veto matter.
HIPAA — PHI never enters a context window. The healthcare template is built against synthetic fixtures. Agents on a HIPAA project run at max_tier: 2 with no egress beyond the allowlist. That is the three-factor rule applied concretely: a session with PHI scope gets no untrusted content and no outbound channel.
